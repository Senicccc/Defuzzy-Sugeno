# Website Penentu Jumlah Produksi Berbasis Fuzzy Sugeno

Web ini dikembangkan untuk membantu menentukan jumlah produksi secara otomatis menggunakan metode logika fuzzy Sugeno. Sistem dirancang berbasis web dan dilengkapi dengan fitur autentikasi pengguna, formulir input, perhitungan fuzzy, penyimpanan data, dan visualisasi grafik.

🔗 **Demo Web:** [https://fuzzy-production.ct.ws](https://fuzzy-production.ct.ws)

## Fitur Utama

- **Autentikasi Pengguna**: Registrasi dan login untuk menjaga keamanan data.
- **Perhitungan Fuzzy Sugeno**: Fuzzyfikasi, inferensi, dan defuzzyfikasi berdasarkan input permintaan dan persediaan.
- **Riwayat Perhitungan**: Menampilkan daftar seluruh perhitungan yang pernah dilakukan.
- **Detail Hasil**: Menyediakan rincian setiap proses fuzzy dalam satu tampilan.
- **Visualisasi Data**: Grafik hasil produksi untuk mempermudah analisis.
- **Tampilan Responsif**: Desain antarmuka sederhana dan mudah digunakan.
